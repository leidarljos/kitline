#+title: kitline quickstart
#+options: toc:nil num:nil ^:{}

One command installs a prebuilt kitline: curl -fsSL https://github.com/leidarljos/kitline/releases/latest/download/install.sh | sh.
The script checks SHA256SUMS, then copies the binary to $HOME/.local/bin.
Set KITLINE_INSTALL_DIR to choose a different directory.

A bare clone, then a plan. kitline does not push.

#+begin_src sh
git clone --bare https://github.com/leidarljos/ljos.git /tmp/ljos.git
kitline triage /tmp/ljos.git --trunk main --out plan.org
#+end_src

plan.org has DROP, STACKS, and ORDER. Parents land before children.

#+begin_src sh
rm -rf /tmp/kitline-qs
git init -b main /tmp/kitline-qs
cd /tmp/kitline-qs
git config user.email rgoswami@ieee.org
git config user.name "Rohit Goswami"
git config commit.gpgsign false
git commit --allow-empty -m "init"
kitline triage . --trunk main --out plan.org
kitline stamp -m "subject line" > msg.txt
git commit --allow-empty -F msg.txt
kitline track HEAD
kitline triage verify plan.org
#+end_src

stamp prints a message carrying Kitline-Change. Commit that message, then
track prints the id. verify re-checks every DROP row.
